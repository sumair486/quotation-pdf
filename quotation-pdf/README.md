# Quotation Maker

Next.js + Tailwind + @react-pdf/renderer. The PDF is generated in the browser.

## Run locally
    npm install
    npm run dev

## Deploy on Vercel (free)
1. Push this folder to a GitHub repo.
2. On vercel.com choose "Add New Project", import the repo, click Deploy.
(No environment variables needed.)

The PDF layout is in `components/QuotationPDF.js`.
